# FORGE·X 演示视频讲解稿｜录制与配音执行版

主版本建议成片时长：10–11 分钟；包含知识检索与分享时约 12 分钟。录制前使用最新版 Chrome 或 Edge，以 `npm start` 启动项目并刷新页面。为避免上一次演示留下的 Profile、校准包和历史数据，使用新的无痕窗口。

## 配音设定

- 声线：沉稳、清晰、有工程感，不使用夸张广告腔。
- 语速：每分钟约 220–240 个汉字；数据、英文缩写和界面术语处主动放慢。
- 节奏：每个镜头开头保留约 1 秒环境画面，旁白结束后保留约 1 秒再转场。
- 音量：人声保持稳定，峰值不高于 `-3 dB`；如使用背景音乐，应持续低于人声约 18–22 dB。
- 录制方式：旁白和屏幕操作分轨录制。先按画面操作完成无声母版，再按本稿配音，便于后期调整停顿。

## 术语统一读法

- `FORGE·X Insight`：读作“Forge X Insight”。
- `FDM`、`OEE`：逐字母读。
- `G-code`：读作“G code”。
- `CoreXY`：读作“Core X Y”。
- `Profile`：保留英文读法。
- `JSON`：读作“Jason”。
- `SHA-256`：读作“S H A 二五六”。
- `holdout`：读作“hold out”。

## 录制执行规则

1. 鼠标移动保持平稳，点击后至少停留 1 秒，让观众看清反馈。
2. 文件选择器、加载动画和长时间打印可剪辑加速，但不能剪掉关键状态变化。
3. 弹出成功提示时暂时不要移动鼠标，至少保留 1.5 秒。
4. 不在同一画面同时打开两个侧边面板，保证视觉焦点单一。
5. 如果某个可选后端能力未启用，按稿件中的跳过说明执行，不临场伪造结果。

## 镜头 04｜工艺参数与真实路径差异｜02:05–03:05

**画面操作**

1. 打开工艺参数面板。
2. 依次点击“精细、标准、草稿、强度”预设，停留观察层数和统计变化。
3. 在相同填充密度下依次切换“直线、斜线网格、蜂窝”。
4. 修改周界圈数、填充密度和层高。
5. 点击“切片”，拖动预览层滑杆并保持“3D 视口联动”开启。

**讲解词**

> 工艺参数不是装饰选项。层高会改变实际层数，周界圈数会生成更多轮廓路径，填充密度会改变材料量，直线、斜线网格和蜂窝也会生成不同的空间路径。切片页可以逐层查看周界、实体填充、稀疏填充、支撑和裙边，并把当前层同步绘制到 3D 视口。

**画面重点**

- 切片统计数值变化。
- 三种填充图案的明显路径差异。
- 2D 层预览与 3D 视口同步。

## 镜头 05｜平台调平与 Z 补偿｜03:05–03:50

**画面操作**

1. 点击“校准”。
2. 点击“运行 3×3 自动调平”。
3. 等待探针完成九点采样。

**画面重点**

- 探针移动过程。
- 热力图从空状态变为完整网格。

## 镜头 06｜仿真打印与实时监控｜03:50–05:05

**画面操作**

1. 将仿真倍率切换为 `8×`。
2. 点击“开始打印”。
3. 立即打开右下角“实时监控”。
4. 展示喷嘴和热床升温曲线、层数、进度、耗材累计和事件日志。
5. 切换“喷头”相机，录制几秒路径执行。
6. 可在打印中调整速度、喷嘴温度或风扇，观察日志和温度曲线。

**讲解词**

> 启动任务后，系统按切片路径执行预热、调平、移动、空驶、回抽和挤出。温度曲线由热惯性模型实时演化，耗材根据正在执行的路径、挤出量和材料密度累计，层数、坐标、进度和日志都与当前任务状态同步。这里展示的是仿真实时遥测，不是实体打印机传感器数据；设备功率与控制负载属于过程估算值。

**画面重点**

- 升温曲线明显爬升。
- 耗材“已用”持续增加。
- 事件日志随阶段更新。

## 镜头 07｜故障演练与恢复｜05:05–05:55

**画面操作**

1. 打印进行中，在监控面板底部点击“热失控”。
2. 等待温度曲线下降和系统进入故障暂停。
3. 展示日志中的“加热器异常、温度偏差、保护触发”链路。
4. 点击暂停/恢复按钮排除故障。
5. 等待温度重新达到目标并继续打印。

**讲解词**

> 故障演练不是只弹出一条提示。以热失控为例，演练首先改变加热器物理状态，实际温度开始下降；监测器持续比较实测温度和目标温度，在偏差达到阈值并持续后触发保护。排障恢复供电后，系统会重新升温并从暂停位置继续任务。整条检测与恢复过程都会进入事件日志和本次运行遥测。

**备选镜头**

如果时间有限，可只录“热失控”；“断料”和“堵料”用于快速展示报警与恢复流程。

## 60 秒精简版旁白

> FORGE·X Insight 是一个本地优先的 FDM 数字实验与生产分析平台。用户可以扩展机器和材料 Profile，也可以把图片生成浮雕或剪影模型。层高、周界、填充和支撑会生成不同的真实切片路径，并支持逐层 2D 与 3D 联动预览。平台调平通过九点采样拟合补偿网格；打印阶段按路径执行温控、移动、回抽和挤出，实时累计进度、耗材与事件遥测。外部 G-code 可以逐层复盘，再与对应任务日志进行时间、耗材和层数对账。校准模型带来源、作用域、holdout、审核和漂移生命周期，合成模型不会自动进入生产。最后，生产任务 CSV 可以通过统计引擎生成带样本量、置信区间、显著性和证据链的分析报告，并联动回 3D 机群视图。

## 录屏用语边界

- 可以说“真实解析的 G-code 路径”，不要说“真实打印机正在运行”。
- 可以说“仿真实时遥测”，不要把温度曲线说成实体传感器读数。
- 可以说“耗材按 E 增量或切片挤出量累计”，不要说“称重传感器实测”。
- 功率、电机和主控区域应称为“过程估算”，不要称为功率计或固件采样。
- `06-demo-production.csv` 和 `04-demo-machine-log.json` 必须称为“合成演示数据”。
- 只有界面明确显示 OpenAI 兼容 provider（环境变量配置或用户自带端点）时才可以称为“AI 分析”；`local-rules` 和 `server-rules` 都是规则引擎。
