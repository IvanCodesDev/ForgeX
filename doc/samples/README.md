# 样例数据说明

## `print_jobs_synthetic.csv`

**⚠ 这是合成数据，不是真实产线数据。**

由 [`js/insight-data.js`](../../js/insight-data.js) 的 `generateSample()` 以固定随机种子
（`20260721`）生成，96 行，确定性可复现。

### 它里面「埋」了什么

这份数据按下列**预先写死的概率**生成，所以任何从它得出的「发现」都是生成器事先放进去的，
**不构成对任何真实设备、材料或工艺的结论**：

| 埋进去的东西              | 写死的值                             |
| ------------------------- | ------------------------------------ |
| FX-256-03 的故障率        | `0.20`（其余机台 `0.04`–`0.06`）     |
| 「ABS × 传感器支架」组合  | 额外 `+0.22` 失败率                  |
| 「PETG × 传感器支架」组合 | 额外 `+0.10` 失败率                  |
| 打印时长                  | 按 `baseMin × (0.2 / 层高)` 直接计算 |

最后一条尤其要注意：所谓「层高与打印时长负相关」**是这行公式的定义，不是数据中发现的规律**。

### 正当用途

- UI 演示与截图
- 回归测试的确定性输入
- 验证 CSV 解析与字段映射

### 不能用来做什么

- 不能用来论证本项目的分析引擎「能发现问题」——它只是把生成参数回显了一遍
- 不能作为任何工艺、设备或采购决策的依据

### 想要真实数据

1. **上传你自己的生产 CSV**（中英文表头宽松匹配，见 `js/insight-data.js` 的 `HEADER_ALIAS`）；
2. **用仿真器采集**：跑几单打印，「洞察」面板的「仿真采集」数据集会记录真实的物理仿真结果
   （温控惯性、床面误差场、故障链都是真实计算的）；
3. 路线图中的**虚拟机群**（P2）会让故障从物理过程中涌现，而不是概率抽样——
   见 [`doc/优化文档.md`](../优化文档.md) §5 P2。

## 字段说明

| 字段              | 含义           | 备注                                                                          |
| ----------------- | -------------- | ----------------------------------------------------------------------------- |
| `job_id`          | 任务 ID        |                                                                               |
| `date`            | 日期           | `YYYY-MM-DD`                                                                  |
| `machine_id`      | 机台编号       |                                                                               |
| `model_name`      | 模型名         |                                                                               |
| `material`        | 材料           | PLA / PETG / ABS / TPU                                                        |
| `layer_height_mm` | 层高（mm）     |                                                                               |
| `duration_min`    | 耗时（分钟）   |                                                                               |
| `filament_g`      | 耗材克重       |                                                                               |
| `cost_fen`        | 成本（**分**） | 以分为最小单位的整数，避免浮点误差；上传时也可用 `cost_cny`（元），会自动换算 |
| `status`          | 结果           | `success` / `fail`（也接受「成功」「失败」「故障」）                          |
| `fail_reason`     | 故障类型       | 见 `FXInsightData.FAULT_TAXONOMY`                                             |
| `energy_kwh`      | 能耗           |                                                                               |

金额由 `FXInsightData.COST_PROFILE` 换算，该口径是**估算值不是权威数据**，可用
`FXInsightData.setCostProfile()` 替换为你自己的采购价。
