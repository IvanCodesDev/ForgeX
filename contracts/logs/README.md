# 真机任务日志

先导入 G-code，再在模型页追加 JSON / CSV 日志。文件须为 UTF-8，可带 BOM；上限 20 MiB、100 万条遥测。JSON 标准格式为 `forgex-machine-log` v1，完整字段见 [schema](machine-log.schema.json)，演示数据见 [示例](example-machine-log.json)。示例中的能耗是演示值，不代表现场测量。

读取、SHA-256、解析和遥测汇总默认在后台线程完成，可查看各阶段进度并点击“取消日志导入”。后台任务 60 秒无结果时结束本次导入；切换模型、重导 G-code 或选择新日志也会取消旧任务。仅后台线程启动失败时启用本机兼容解析，界面会标明；该兼容路径的同步解析阶段可能短暂占用界面线程，取消与超时在异步阶段生效。解析错误不会在界面线程重跑。

CSV 按行消费中间记录，不保留整份行数组及每行对象副本。后台仍校验全部遥测，但仅向界面回传样本数、有效时间/温度范围和任务汇总，最大 32 KiB；过长的任务或设备文字字段会被拒绝。工作台状态不保留原始遥测数组，原始文件仍由用户持有，日志原件摘要和成本审计不变。温度范围是记录的最小/最大值，不代替缺失记录或计量能耗。

`job.gcodeSha256` 填写 G-code **原始文件字节**的 SHA-256。摘要不一致的日志会被拒绝。缺少摘要的旧日志可以查看汇总与未绑定提示，但不参与成本对账或时间校准。导入入口另计算日志原始字节摘要，成本对账导出同时保留两份文件的关联及 C# 成本指纹。摘要验证只证明文件关联，不证明日志真实性。

任务汇总可提供：

- `durationSec`：任务持续秒数。缺失时可从遥测最大和最小时间之差取得跨度，但会提示其可能未覆盖完整任务。明确填写 0 不触发回退。
- `filamentG`、`filamentMm`：任务消耗克重与长度；成本核算只使用克重，不从长度自行猜测材料密度。
- `completedLayers`、`status`：完成层数及任务状态。取消、失败或未完成的任务可能只有部分消耗。
- `energyKwh`：**该任务消耗电量**，非负、最高 1000000 kWh。没有记录就省略；明确记录零消耗时填写 0。
- `energyEvidence`：最多 500 字的计量依据，例如计量设备编号、任务起止区间、起止读数和差额取得方式。系统不替用户验证记录。能耗数值缺少依据时仍可查看，但不参与电费或总成本核算。

CSV 使用表头 `time_s,nozzle_c,bed_c,job_id,machine_id,gcode_sha256,duration_s,filament_g,energy_kwh,energy_evidence,status` 等常见名称；任务时长、耗材、能耗和状态取最后一行汇总。设备、任务、固件、切片器及 G-code 摘要可只填在部分行，但所有非空声明必须一致，避免把多个任务混在一起。`time_s` 或 `elapsed_s` 为遥测时间，未提供 `duration_s` / `duration_sec` 时使用时间跨度。带逗号或换行的依据必须用双引号包围，内部双引号写为两个双引号。重复表头、列数不一致、未闭合引号和非法数值会被拒绝。

```csv
time_s,nozzle_c,bed_c,filament_mm,filament_g,completed_layers,energy_kwh,energy_evidence,status
0,25,25,,,,,,running
4380,207.2,58.7,8240,24.7,120,0.26,"演示数据，非真实测量",success
```

差异视图不会判定哪一侧“正确”：G-code 时间按运动速度重算，真机日志通常还包含预热、加速度、固件宏、暂停和换层；耗材也可能来自 E 值、编码器或称量，口径必须和日志来源一起解释。

缺失、null 和空白保持未知；0 是显式零值。不会将空白解释为 0，也不会从温度或声明平均功率伪造日志实测能耗。

成本对账需先完成 C# 异步作业的成本估算，再追加匹配摘要的日志，在“能耗与机时成本估算”中查看：

- 电费 = 日志任务消耗电量 × 同一电价；机时成本 = 日志秒数 ÷ 3600 × 同一纯机时费率；材料成本 = 日志克重 ÷ 1000 × 同一材料单价。
- 日志核算不需要声明平均功率；计划侧功率未知时，日志侧仍可利用有依据的消耗电量核算电费。
- 分项缺少来源或费率时显示未知，总额仅在三个费用分项都可计算时提供。差值为日志减计划；计划为 0 时不计算相对百分比。
- 计划值保留 C# 模型 v2 的舍入结果；日志核算模型 `forgex-machine-cost-comparison/1` 使用浏览器浮点数计算并在导出中保留数值，显示金额到分。两侧时间口径可能不同，结果用于复盘，不作为结算账单。

修改成本输入后，旧估算与对账立即清空；选择新日志时，旧日志对账立即清空。切换模型或重新导入 G-code 会取消旧日志导入，旧摘要晚到也不会恢复结果。
