# FORGE·X Insight — 3D 打印仿真 × 生产数据分析

**简体中文** · [English](./README.en.md)

一个**物理仿真驱动**的增材制造工具：左边是能真实切片、真实温控、真实产出 G-code 的 3D 打印仿真器，
右边是对生产数据做聚合分析的洞察面板。

---

## 快速开始

```bash
# 方式一：零依赖直开（无需 Node、无需联网）
双击 index.html

# 方式二：带后端（仍然零 npm 依赖，无需 npm install）
node server/index.js     # 或 npm start
# 打开 http://127.0.0.1:8787
```

跑测试：

```bash
npm test        # 409 项断言，零依赖，无需 install
```

## 这个项目里，什么是真的

开源项目最重要的是可信度，所以先把话说清楚。

### ✅ 真实的部分

| 能力               | 为什么可信                                                                                                                                                                                       |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **切片引擎**       | 周界偏置 → 奇偶规则扫描线填充 → 顶底实心层 → 悬垂支撑 → 裙边，都是真算法（`js/slicer.js`，32 项断言）                                                                                            |
| **温控物理**       | 一阶滞后 + 过冲 + 噪声的热惯性模型；热失控保护凭实测偏差自行发现（参考 Marlin 语义），不是脚本触发                                                                                               |
| **调平数据链**     | 机型固有床面误差场（确定性）→ 9 点探针实测 → 拟合 5×5 补偿网格 → 打印时按喷头位置双线性插值实时补偿 Z。未调平直接打印会得到真实的首层不均匀度警告                                                |
| **四套运动学**     | CoreXY 封闭式 / i3 龙门 / Delta 并联臂逆解 / 大幅面龙门，是分别实现的，不是换皮（`js/printers.js`）                                                                                              |
| **G-code 导出**    | 由真实切片路径生成，挤出量按 ⌀1.75 耗材换算，ΣE 与切片统计守恒（有断言核验），可直接进 Cura / PrusaSlicer                                                                                        |
| **成品实测质量**   | 温度偏差积分、调平残差、变速时间占比、故障实录全部来自本次打印的真实遥测，不是预设评分                                                                                                           |
| **故障从物理涌现** | 五类故障（堵料/断料/热失控/翘边/悬垂塌陷）没有一类来自概率抽样：每台机器有确定性的固有物理特征（热端积碳、送料咬合力、加热器功率、环境风扰），故障是这些特征与本单工艺参数相互作用越过阈值的结果 |
| **虚拟机群数据集** | `tools/farm-sim.js` 用物理仿真批量产出生产数据，同 seed 逐行可复现。默认数据集就是它产的                                                                                                         |

### ⚠️ 需要说清楚的部分

| 事项                     | 实情                                                                                                                                                                                                       |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **「分析引擎」不是 AI**  | 默认引擎（本地与后端）是**规则引擎**：关键词意图路由 + 确定性聚合统计，只覆盖 5 个分析维度。界面上会明确标注「规则引擎（无 AI）」。问题超出这 5 个维度时，它会**明说没听懂**并列出支持的维度，不会假装回答 |
| **默认数据仍是仿真数据** | 默认数据集由虚拟机群物理仿真产出——**不是概率抽样**，结论可被证伪（改工艺参数，故障分布会跟着变）。但它终究不是真实产线数据，UI 上带「机群仿真」标记。详见 [`datasets/README.md`](./datasets/README.md)     |
| **AI 只负责叙述**        | 接 AI 后**数字仍由本地统计核算**，AI 只把已核验的事实组织成叙述。这不是限制而是设计：LLM 不擅长在上下文里做假设检验，让它复述算准的数比让它自己算安全得多。图表、视口联动、置信区间在 AI 模式下同样具备    |
| **机群视图是低模的**     | 机群用低模机柜表示，细节打印机模型只保留给当前选中那台——机群视图要看的是「哪台有问题」，不是「喷头长什么样」                                                                                               |
| **全内存，无持久化**     | 数据源 / 任务 / 分享页都在内存，重启即失效。分享页「24 小时有效」指进程存活期内                                                                                                                            |
| **无鉴权、无配额**       | 公网部署前请务必看「部署注意」一节                                                                                                                                                                         |

### ❌ 目前没有的

- **连接实体打印机**（可导出 G-code / STL / OBJ 进入实体工作流）

## 功能总览

| 区域          | 内容                                                                                        |
| ------------- | ------------------------------------------------------------------------------------------- |
| 顶部流程胶囊  | 模型（含摆放变换）· 切片 · 校准 · 质量 · **洞察**                                           |
| 智造洞察面板  | 数据接入（合成示例 / 上传 CSV / 仿真采集）、KPI 看板、提问、报告与图表、分析历史            |
| 参数浮层      | 工艺预设、材料体系（PLA/PETG/ABS/TPU 联动）、层高、周界、填充、温度、速度、回抽、风扇、支撑 |
| 底部控制 Dock | 进度环、开始/暂停/停止、当前层、剩余时间、喷嘴/热床温度                                     |
| 监控浮层      | 温度实时曲线、耗材余量、设备负载、事件日志、故障演练注入                                    |
| 全屏 3D 视口  | 打印机仿真 + 逐层打印动画，左键旋转 / 右键平移 / 滚轮缩放，三个相机预设                     |

### 仿真细节

- 切片面板滑块可在 **3D 视口中直接预览任意层的真实挤出路径**（与 2D 预览同源数据）；
- 预热 → 3×3 自动调平 → 逐层打印 → 完成的全状态机；
- 温度 / 速度 / 风扇支持打印中实时调整；几何参数打印中锁定（与真实切片器行为一致）；
- 故障演练：断料 / 堵料为传感器直报；**热失控演练注入的是「加热器失效」这一物理扰动**——温度按热惯性真实下跌，由热失控监测器凭实测偏差自行发现并切断加热。

### 图片转 3D 打印

「模型」面板支持拖拽 PNG / JPG / WebP：

- **浮雕模式**：图像亮度映射为表面高度（类 Lithophane）；
- **剪影模式**：按亮度阈值提取主体轮廓整体挤出；
- 可调成品宽度（40–140mm）、最大高度、明暗反转，修改后自动重新切片。

### 数据分析

支持的 5 个分析维度（超出会明说）：

1. 机台故障率排行与归因
2. 材料失败率对比
3. 层高与打印时长的关系
4. 成本趋势与拆解
5. 失败批次归因

分析引擎的统计纪律：

- **最小样本量守卫**：每组需 ≥ 5 个任务才参与排名——避免「跑过 1 单且失败」的机台以 100% 故障率登顶；
- **可信度标注**：每份报告带 `confidence`，样本不足时明确拒绝给结论，而不是硬挑一个；
- **混杂因素披露**：相关性分析会说明未控制材料/模型差异，不把相关当因果；
- **计价口径随报告披露**：金额换算用的单价表是**估算值不是权威数据**，报告里会连同出处一起给出，可用 `FXInsightData.setCostProfile()` 替换。

### 成品导出

| 格式                      | 内容                                  |
| ------------------------- | ------------------------------------- |
| STL（二进制）             | 成品三角网格，含当前缩放，Z-up        |
| OBJ（ASCII）              | 通用三维格式                          |
| **G-code**（Marlin 风格） | 由真实切片路径生成，ΣE 与切片统计守恒 |

```bash
node tests/insight.test.js   # 洞察：数据/解析/统计守卫/来源标记/统计严谨性（88 项）
node tests/farm.test.js      # 虚拟机群：物理特征确定性/涌现区分度/效应可调转/证据自洽（48 项）
node tests/server.test.js    # 后端契约 + provider 抽象 + 简报 + 缓存 + 检索（98 项）
node tests/check-refs.js     # HTML ↔ JS 的 DOM id 引用交叉校验

node tests/deploy-check.js https://你的域名   # 部署后线上冒烟
```

**测试原则**：断言引擎的**性质**，不断言「生成器埋了什么就挖出什么」。
例如故障排行的测试会自己构造带已知效应的数据集，检验引擎能否识别；
并额外验证「把效应调转，结论必须跟着调转」——证明它在算数据，不是在读常量。

## 部署注意

⚠️ **在公网部署前必读**：

当前**没有鉴权、没有配额、没有并发上限**。若配置了 InfiniSynapse 密钥并公开访问，
任何人都能持续触发真实云端任务，**费用记在你的账上**。

公网部署建议：

- **不配置** `INFINI_API_KEY`（只跑规则引擎），或
- 自行在反向代理层加访问控制，或
- 等待路线图 P4 的成本闸门。

## 已知限制

- 本平台为**模拟器**：不连接实体打印机；
- 蜂窝填充图案在视觉上以斜线网格呈现；
- 建议桌面端 ≥1280px 宽度使用；
- WebGL 被系统策略禁用时无法运行，会给出明确提示；
- Chromium <84 上部分间距略有退化（flex gap 不支持），不影响功能。
